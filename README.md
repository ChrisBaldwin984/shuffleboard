# Shuffleboard Scorer

One-tap scorer for pub table shuffleboard, built for a few mates taking turns two at a time.

Live at https://chrisbaldwin984.github.io/shuffleboard/

- Big +1 / +2 / +3 / +4 / +6 buttons per player (editable in Setup)
- Running totals to a target (21 by default), undo, editable names
- Rotation: take turns (longest on sits out) or winner stays on
- League table and results for the night

It is a single static page (`index.html`). Scores save in the browser of the phone keeping score.
